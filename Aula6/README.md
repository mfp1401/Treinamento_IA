# Aula 6 — ML na mão, com NumPy

Neste módulo os algoritmos deixam de ser caixas-pretas: cada um é **implementado do zero com NumPy** e, no final, comparado com a versão do scikit-learn para provar que a implementação está correta.

## Sub-aulas

| Aula | Tema | Desafio de casa |
|---|---|---|
| [6.1](Aula6.1/README.md) | Álgebra linear e cálculo para ML | módulo `algebra.py`: normas, distâncias, MSE e gradiente |
| [6.2](Aula6.2/README.md) | Regressão linear pela equação normal | classe `MinimosQuadrados` |
| [6.3](Aula6.3/README.md) | Gradiente descendente | classe `GradienteDescendente` + animação |
| [6.4](Aula6.4/README.md) | Regressão logística do zero | classe `RegressaoLogistica` |
| [6.5](Aula6.5/README.md) | Métricas de classificação | `meu_classification_report` + ROC/AUC |
| [6.6](Aula6.6/README.md) | Validação cruzada | `meu_kfold`, `meu_stratified_kfold`, `meu_cross_val_score` |
| [6.7](Aula6.7/README.md) | KNN do zero | KNN com loops × broadcasting |
| [6.8](Aula6.8/README.md) | Naive Bayes do zero | filtro de spam |
| [6.9](Aula6.9/README.md) | Árvore de decisão do zero | árvore própria no dataset Iris |

Cada pasta tem `exercicio_guiado.py` (feito em aula), `desafio.py` (desafio de casa) e um `README.md` com o resumo e os resultados.
