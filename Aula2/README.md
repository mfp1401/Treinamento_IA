# Aula 2 — Introdução ao Python

Primeiros passos na linguagem: como guardar valores, tomar decisões e repetir tarefas. Os exemplos usam situações do dia a dia (times de futebol, notas de alunos) para praticar cada estrutura.

## Conteúdos

- Variáveis e tipos de dados (`str`, `int`, `float`)
- Condicionais (`if` / `else`)
- Listas: índices e fatiamento (`[0]`, `[1:3]`, `[-1]`)
- Dicionários
- Laços `for` e `while`
- Contadores e acumuladores

## Arquivos

| Arquivo | O que faz |
|---|---|
| `01_variaveis.py` | cria variáveis e mostra o tipo de cada uma com `type()` |
| `02_condicionais.py` | compara a idade de duas pessoas com `if` / `else` |
| `03_listas.py` | acessa elementos e fatias de uma lista de times |
| `04_dicionarios.py` | dicionário com times e anos de fundação |
| `05_dicionario_com_if.py` | verifica pela pontuação se cada time será rebaixado |
| `06_for.py` | percorre times e pontos com `for` |
| `07_while.py` | conta jogadores até o jogo terminar por W.O. |
| `08_exercicio_final.py` | conta aprovados e reprovados a partir de uma lista de notas |
