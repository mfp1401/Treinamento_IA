# Aula 3 — NumPy, Pandas e Matplotlib

As três bibliotecas base da ciência de dados em Python: **NumPy** para contas com arrays, **Pandas** para tabelas (DataFrames) e **Matplotlib** para gráficos. Juntas, elas permitem a análise exploratória de dados (EDA), que vem antes de qualquer modelo.

## Conteúdos

- NumPy: arrays e estatísticas (`mean`, `max`, `min`, `sum`)
- Pandas: criar DataFrames, `head`, `tail`, `shape`, `describe`, `info`
- Seleção de colunas, filtros e ordenação (`sort_values`)
- Valores ausentes (`isnull`)
- Matplotlib: gráficos de barras, histogramas e dispersão

## Arquivos

| Arquivo | O que faz |
|---|---|
| `01_numpy.py` | média, máximo, mínimo e soma de um array de notas |
| `02_resumo_comandos_pandas.py` | resumo de referência dos principais comandos do Pandas (não é para executar) |

| `04_matplotlib.py` | gráfico de barras e histograma de faltas |
| `05_exercicio_matplotlib.py` | barras, histograma e dispersão com dados de alunos |
